# Knowledge Base Schema (History)

Extends minimal schema with history domain-specific entity and concept types.

## Entity Types

| Type | Template | Description |
|------|----------|-------------|
| person | person-template.md | Historical persons (emperors, officials, scholars, generals) |
| place | place-template.md | Historical places (capitals, prefectures, passes, battlefields) |
| event | event-template.md | Historical events (wars, coups, reforms, diplomacy) |
| institution | institution-template.md | Political institutions (councils, ministries, academies) |

## Concept Types

| Type | Template | Description |
|------|----------|-------------|
| dynasty | dynasty-template.md | Dynastic periods (Han, Tang, Song, etc.) |
| policy | policy-template.md | Policies and reforms (land reform, tax systems) |
| culture | culture-template.md | Cultural concepts (Confucianism, Buddhism, Taoism) |
